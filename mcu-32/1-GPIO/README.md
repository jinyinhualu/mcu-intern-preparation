## 1. GPIO 的输入和输出路径

图 13 中，I/O 引脚同时连接输入和输出相关电路。配置模式决定哪些电路工作。

- 输入路径：引脚 → 施密特输入电路 → 输入数据寄存器 `GPIOx_IDR`。
- 通用输出路径：输出数据寄存器 `GPIOx_ODR` → 输出控制 → P-MOS/N-MOS → 引脚。
- 内部上下拉：通过可控的电阻支路，把引脚弱连接到 `VDD` 或 `VSS`。

`VDD` 是电源，`VSS` 是地。高低电平是对引脚电压的逻辑判定，不要求高电平恰好等于电源电压、低电平恰好等于 0 V；具体判定范围取决于芯片规格。

## 2. 上拉、下拉和浮空

数字输入模式下，输出缓冲器被禁止，施密特输入被激活；根据配置接入弱上拉、弱下拉，或断开两者。

以上拉输入和接地按键为例：

```text
VDD
 |
上拉电阻
 |
 +------ GPIO 输入
 |
按键
 |
GND
```

- 按键松开：没有外部驱动时，上拉电阻提供默认高电平。
- 按键按下：引脚接地，读到低电平；电流沿 `VDD → 上拉电阻 → 按键 → GND` 流动。
- 上拉电阻既提供默认状态，又在按键闭合时限制电流；它不能“始终保证高电平”。
- 下拉与上拉类似，但默认把引脚拉向地。
- 浮空输入：内部上下拉均不接入。若外部也没有驱动，引脚电压不确定，可能受干扰、漏电或残留电荷影响。偶尔读到稳定值也不能证明可靠。

高阻是电气特性，不是第三种逻辑电平。高阻输入若有外部驱动或上拉，仍可具有确定电压；“高阻”不能直接等同于“悬空”。

## 3. 推挽与开漏

根据第 108 页 8.1.8，可整理为：

| 输出模式 | ODR 对应位 | P-MOS | N-MOS | 引脚行为 |
| --- | --- | --- | --- | --- |
| 推挽 | 0 | 关闭 | 导通 | 主动拉低 |
| 推挽 | 1 | 导通 | 关闭 | 主动拉高 |
| 开漏 | 0 | 关闭 | 导通 | 主动拉低 |
| 开漏 | 1 | 关闭 | 关闭 | 释放引脚，呈高阻 |

开漏写 1 不等于主动输出高电平。若没有外部上拉或其他外部驱动，释放后不能保证高电平。该 STM32F1 手册说明，输出配置下内部弱上拉、弱下拉被禁止，不能把输入上拉配置直接套用到开漏输出。

### 两个推挽输出相连

若 A 写 1、B 写 0，形成：

```text
VDD → A 的 P-MOS → 公共连线 → B 的 N-MOS → VSS
```

一端主动拉高、另一端主动拉低，发生输出冲突。电流可能过大，连线电压取决于两侧驱动特性，可能落在不能保证有效识别的范围。即使器件还没有损坏，也不能保证有效电平；损坏是可能的后果，不是电平不确定的前提。

### 两个开漏输出共用一个外部上拉

A 写 1、B 写 0 时，A 释放，B 拉低，电流路径是：

```text
VDD → 外部上拉电阻 → 公共连线 → B 的 N-MOS → VSS
```

不是流经写 1 的 A 支路。外部电阻限流；没有主动拉高的一方，是此时不存在推挽式输出冲突的根本原因。

| A 写入 | B 写入 | 连线电平 |
| --- | --- | --- |
| 0 | 0 | 低 |
| 0 | 1 | 低 |
| 1 | 0 | 低 |
| 1 | 1 | 高，由外部上拉建立 |

结论：任何一个拉低，连线就低；全部释放，连线才高。这里假设供电、上拉阻值和负载符合电气要求，不代表任何接法都安全。

## 4. 施密特输入与按键消抖

手册说明数字输入配置会激活施密特触发输入。其基础原理是上升和下降使用不同门限，两个门限之间保持先前状态，称为滞回。

教学假设（不是 STM32F1 实际规格）：上升超过 2.0 V 才变高，下降低于 1.0 V 才变低。

- 输入从 0 V 升到 2.2 V：判定变高。
- 随后降到 1.8 V：尚未低于下降门限，保持高。
- 同样是 1.8 V，如果此前一直为低且没有越过上升门限，则仍保持低。

滞回有助于避免慢边沿或噪声导致的反复翻转，但不能笼统认为“小幅噪声一定被过滤”，需要结合当前状态和是否跨越相应门限判断。

机械按键可能在接近 0 V 和 VDD 之间多次通断，反复越过两个门限，因此施密特输入不能替代按键消抖。是否形成多个应用事件，还取决于软件如何检测、计数和过滤这些变化；并非每次物理抖动必然对应一次事件。

## 5. 怎么读表 17 和表 18

每个引脚在 `GPIOx_CRL` 或 `GPIOx_CRH` 中占一个四位配置字段，位序为：

```text
CNF1 CNF0 MODE1 MODE0
```

先看 MODE，再按输入或输出解释 CNF，必要时再看 ODR。

| MODE[1:0] | 含义 |
| --- | --- |
| 00 | 输入模式 |
| 01 | 输出模式，最大输出速度 10 MHz |
| 10 | 输出模式，最大输出速度 2 MHz |
| 11 | 输出模式，最大输出速度 50 MHz |

表 18 是“输出模式位”表，所以把 00 标为保留；结合表 17 看完整 GPIO 配置，MODE=00 用于输入。两张表的上下文不同，不应因此把输入配置当成非法值。

这些速度档位用于选择输出驱动速度，不会让引脚自动产生对应频率的方波，也不是要求所有输出都使用 50 MHz。实际选择还要结合负载和信号速度。

当 MODE=00 时：

| CNF[1:0] | 输入配置 |
| --- | --- |
| 00 | 模拟输入 |
| 01 | 浮空输入 |
| 10 | 上拉/下拉输入；ODR=1 选上拉，ODR=0 选下拉 |
| 11 | 保留 |

当 MODE≠00 时：

| CNF[1:0] | 输出配置 |
| --- | --- |
| 00 | 通用推挽输出 |
| 01 | 通用开漏输出 |
| 10 | 复用推挽输出 |
| 11 | 复用开漏输出 |

通用输出由 GPIO 输出数据控制；复用输出由对应片上外设的输出信号驱动。CNF 的含义依赖 MODE，不能只看 CNF 就判断模式。

本轮例子：

| 需求/配置 | 解读 |
| --- | --- |
| 输入上拉 | MODE=00，CNF=10，ODR 对应位=1 |
| 输入下拉 | MODE=00，CNF=10，ODR 对应位=0 |
| 通用推挽输出，2 MHz | CNF=00，MODE=10，四位字段为 0010b，即 0x2 |
| 通用开漏输出，50 MHz | CNF=01，MODE=11，四位字段为 0111b，即 0x7 |

输入上拉、下拉的四位字段都为 1000b，即 0x8，区别在另一个寄存器 ODR 的对应位。0x8 只是一个引脚的配置字段，不能不加定位就当作整个 CRL/CRH 的配置值。

读懂表的用途：把电路需求转换成配置、核对 HAL 初始化后的寄存器，以及排查输入读不到、开漏线拉不高等问题。今天只做到解释编码，尚未独立实现寄存器初始化。

## 6. GPIO 寄存器学习（2026-09-22）

本轮继续使用参考手册第 8 章 GPIO 寄存器描述，以及第 6 章 `RCC_APB2ENR`。先读寄存器字段，再手工推导目标引脚的位置，最后把配置、输出控制和输入读取串成完整代码。

### 寄存器分工

| 寄存器 | 作用 | 关键点 |
| --- | --- | --- |
| `GPIOx_CRL` | 配置 Px0～Px7 | 每个引脚占 4 位 |
| `GPIOx_CRH` | 配置 Px8～Px15 | 每个引脚占 4 位 |
| `GPIOx_IDR` | 读取引脚实际采样状态 | 只读，`IDR[n]` 对应 Px n |
| `GPIOx_ODR` | 保存输出控制值 | 输入上下拉模式下，ODR 位选择上拉或下拉 |
| `GPIOx_BSRR` | 单独设置或清除 ODR 位 | 低 16 位设置，高 16 位清除 |
| `GPIOx_BRR` | 单独清除 ODR 位 | bit n 写 1 清除 ODR[n] |
| `GPIOx_LCKR` | 锁定 CRL/CRH 配置 | 锁定后直到系统复位才能改变 |

### CRL/CRH 字段定位

- Px0～Px7 使用 `GPIOx_CRL`，引脚 n 的字段为 bit `4n+3:4n`。
- Px8～Px15 使用 `GPIOx_CRH`，引脚 n 的字段从 bit `4(n-8)` 开始。

例子：

```text
PA5 → CRL bit 23:20
PA9 → CRH bit 7:4
PB10 → CRH bit 11:8
```

修改字段必须先清除再写入，避免旧的 CNF/MODE 位残留：

```c
GPIOB->CRH &= ~(0xFU << 8);
GPIOB->CRH |=  (0x8U << 8);
```

如果原字段为 `0100`，直接 `|= 0010` 会得到 `0110`，最终变成开漏输出而不是推挽输出。这是按位或不能清除旧 1 位造成的。

### IDR、ODR 和开漏实际状态

`ODR` 表示软件写入的控制值，`IDR` 表示引脚实际采样值。开漏输出写 1 是释放引脚，不代表引脚已经为高：

```text
ODR10 = 1，外部器件拉低 → IDR10 = 0
ODR10 = 1，外部上拉且无人拉低 → IDR10 = 1
```

读取单个引脚时要移位并掩码，保证结果只有 0 或 1：

```c
int level = (GPIOB->IDR >> 10U) & 1U;
```

### BSRR、BRR 与读改写

根据第 115 页：

```text
BSRR bit n      = 1 → ODR[n] 置 1
BSRR bit n + 16 = 1 → ODR[n] 清 0
BRR   bit n     = 1 → ODR[n] 清 0
```

写 0 表示不操作。如果同一 BSRR 写入中某一位的 BS 和 BR 同时为 1，手册规定 BS 起作用。

相比 `ODR |= mask` 或 `ODR &= ~mask`，BSRR/BRR 可以只发送目标位的设置/清除命令，避免读改写期间被中断插入后覆盖其他位的更新。

### GPIO 时钟和 LCKR

GPIOB 位于 APB2。参考手册第 70～71 页中，`RCC_APB2ENR` 的 bit 3 是 `IOPBEN`：

```c
RCC->APB2ENR |= (1U << 3);
```

`GPIOx_LCKR` 的锁定序列是：写 1 → 写 0 → 写 1 → 读 0 → 读 1。锁定成功后，对应 CRL/CRH 配置直到下一次系统复位前不能改变。

### PB10 输入上拉的完整寄存器代码

```c
RCC->APB2ENR |= (1U << 3);          // 开启 GPIOB 时钟
GPIOB->BSRR = (1U << 10);           // ODR10 = 1，选择输入上拉
GPIOB->CRH &= ~(0xFU << 8);         // 清除 PB10 的 bit 11:8
GPIOB->CRH |=  (0x8U << 8);         // CNF=10, MODE=00：输入上拉/下拉
int level = (GPIOB->IDR >> 10U) & 1U;
```

其中 `0x8` 的四位字段为 `1000b`；按键接地时，松开读 1，按下读 0。当前代码是寄存器推导练习，尚未在真实 STM32 工程中编译、烧录、接线或测量。下一步是用 HAL 配置同一个 PB10，再逐项对照 HAL 生成的寄存器结果。
