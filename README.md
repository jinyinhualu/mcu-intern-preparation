# 单片机开发实习准备

这个仓库用于记录 18 周单片机开发实习准备过程中的代码、实验结果、问题和复盘。

## 目录

- `study-log/`：按日期记录学习过程、能力变化和问题清单。
- `c-language/`：C 语言基础、综合练习和面向单片机开发的代码实验。
- `cann-operator-contest/`：CANN 算子赛学习分支，用于记录算子开发、刷题、测试准备和复盘。
- `README.md`：项目说明和仓库使用约定。

## 每次学习后的最小记录

1. 今天实际完成了什么。
2. 哪个问题已经能独立解决。
3. 哪个问题目前只能看懂，不能独立写出。
4. 哪个问题完全不会，下一步准备如何验证。

## Git 使用约定

每完成一个可以回退的阶段，就保存一次提交。例如：

```text
docs: 建立学习记录结构
study: 完成 C 语言指针摸底
feat: 完成 STM32 串口打印实验
```
