## 实际完成

### 1. 时钟树中的分支、选择器与 CSS

最初不能理解图中 HSI 的两条支路、多输入单输出的梯形符号，以及 CSS 到 SW 的连线。经拆解后明确：

- 梯形符号是多路选择器；它从输入中选择一个送到输出，不把多个频率相加。
- HSI 的标称 8 MHz 可以直接送到 SW，也可以经过固定二分频，以 4 MHz 送到 PLLSRC；普通分支点本身不改变频率。
- PLLSRC 选择 PLL 的输入：HSI÷2 或 HSE 支路。HSE 支路还有原频率/二分频的选择。
- SW 选择 SYSCLK 来源：HSI、HSE 或 PLLCLK。开启 PLL 与选中 PLLCLK 是两件事。
- CSS 监测 HSE；其到选择器的连线表达故障切换控制，不是第四路时钟。CSS 启用且 HSE 直接或经 PLL 供给 SYSCLK 时，HSE 故障会使系统切换到 HSI。

回测时正确回答：即使 PLL 输出 72 MHz，只要 SW 选择 HSI，SYSCLK 仍为标称 8 MHz。

### 2. 从系统时钟到 TIM2 输入时钟

工程按 HSE=8 MHz、HSE 支路不分频、PLL×9、AHB÷1、APB1÷2 配置。以晶振确实为 8 MHz、初始化成功为前提：

```text
HSE 8 MHz → PLL×9 → SYSCLK 72 MHz
→ AHB÷1 → HCLK 72 MHz
→ APB1÷2 → PCLK1 36 MHz
→ 定时器时钟×2 → TIM2 输入时钟 72 MHz
```

STM32F103 对应 APB 分频系数为 1 时，定时器输入时钟等于 PCLK；分频系数不为 1 时，定时器输入时钟等于 2×PCLK。此规则不直接套用于 USART 等普通 APB 外设。

独立回答了 APB1 改为÷4 时，`PCLK1=18 MHz、TIM2 输入时钟=36 MHz`。定时器仍是 PCLK1×2，不是随 APB 分频系数改成×4。

### 3. 正向手算与参数变化

本轮公式限定为内部时钟、向上计数、边沿对齐、PWM 模式 1、高有效极性，且 0≤CCR1≤ARR+1：

```text
fCNT = fTIM / (PSC + 1)
Δt = 1 / fCNT
T = (ARR + 1) / fCNT
fPWM = 1 / T
tHIGH = CCR1 / fCNT
D = CCR1 / (ARR + 1)
```

基准参数为 `fTIM=72 MHz、PSC=199、ARR=7199、CCR1=540`。各题互相独立，从基准配置出发：

| 配置 | fCNT | 周期 | PWM 频率 | 高电平时间 | 占空比 |
| --- | --- | --- | --- | --- | --- |
| 基准配置 | 360000 Hz | 20 ms | 50 Hz | 1.5 ms | 7.5% |
| 只改 CCR1=1080 | 360000 Hz | 20 ms | 50 Hz | 3 ms | 15% |
| 只改 PSC=399 | 180000 Hz | 40 ms | 25 Hz | 3 ms | 7.5% |
| 只改 ARR=3599 | 360000 Hz | 10 ms | 100 Hz | 1.5 ms | 15% |
| 只把 APB1 从÷2改为÷4 | 180000 Hz | 40 ms | 25 Hz | 3 ms | 7.5% |

基准题与只改 CCR1 的题目全部答对。只改 PSC 时，最初答成 `40 ms、25 Hz、6 ms、15%`，其中后两项对应同时把 CCR1 改成 1080 的情况；经纠正明确独立题必须恢复基准参数。随后只改 ARR 的题目，以及 APB1÷4 的整条链路均答对。

理解了两个计数边界：从 0 数到 ARR 一轮有 ARR+1 个节拍；`CNT<CCR1` 对应 CCR1 个高电平节拍，所以 CCR1 不再加 1。

### 4. PWM 由硬件自动生成

最初认为空主循环仍能输出，是因为“在中断中比较 CCR 和 ARR”。纠正后明确：

```text
定时器时钟 → PSC → CNT 递增
CNT 与 CCR1 比较 → 改变通道输出电平
CNT 到 ARR 后，在下一计数节拍回到 0 → 下一轮
```

- 比较的是 CNT 与 CCR1，ARR 决定计数周期。
- PWM 不依赖中断服务函数逐次判断或写 GPIO；`HAL_TIM_PWM_Start()` 启动后，硬件自动生成波形。
- CPU 可以配置参数、修改比较值或停止定时器，但每轮生成不需要 CPU 参与。
- 回测正确回答：CPU 连续处理其他任务 10 ms，且不修改或停止 TIM2 时，原本 1.5 ms 的高电平不会被拖长到 10 ms。

### 5. 反向配置与模拟故障排查

给定 TIM2 输入时钟 72 MHz、希望 CNT=1 MHz、PWM=1 kHz、高电平占空比 25%，正确补出：

```c
htim2.Init.Prescaler = 72 - 1;
htim2.Init.Period = 1000 - 1;
sConfigOC.Pulse = 250;
```

反算得到每节拍 1 μs，周期 1 ms，高电平 250 μs，低电平 750 μs。完成的是给定条件下的参数补写，没有从空白创建完整 PWM 工程。

在模拟测量题中，目标为 20 ms/1.5 ms，测量假设为 40 ms/3 ms，占空比均为 7.5%。已确认有效 ARR=7199、CCR1=540 时，正确反算 `fCNT=7200/0.040=180000 Hz`，并提出先查时钟树、定时器输入时钟和 PSC。周期正确而脉宽异常时，再重点检查 CCR、PWM 模式与极性。
