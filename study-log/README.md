# study-log

这里保存每天的学习记录，文件名使用 `YYYY-MM-DD.md`，例如 `2026-09-03.md`。

## 三种能力分类

- **能独立完成**：不看教程或现成代码，也能写出、运行并解释；遇到小错误能自己定位。
- **只能看懂**：看别人代码或跟着教程能理解，但从空白开始还写不出来，或者不能独立调试。
- **完全不会**：看到名词或代码仍不知道它解决什么问题，也不能说明验证方法。

分类的依据是“能否独立完成并解释”，不是“以前是否见过”。同一个知识点以后可以从“完全不会”移动到“只能看懂”，再移动到“能独立完成”。

## 每日记录模板

```markdown
# YYYY-MM-DD 学习记录

## 今日目标

## 实际完成

## 新发现的问题

## 能独立完成

## 只能看懂

## 完全不会

## 下一步
```
