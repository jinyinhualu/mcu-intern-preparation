## 实际完成

- 正确定位 PA5 使用 `GPIOA_CRL` bit 23:20。
- 正确定位 PA9 使用 `GPIOA_CRH` bit 7:4，并修正代码应使用 `CRH` 和左移 4。
- 正确定位 PB10 使用 `GPIOB_CRH` bit 11:8，并理解 `(10-8)*4 = 8` 的字段起始位置。
- 能把 `CNF/MODE` 组合成字段值：PB10 输入上拉为 `0x8`，PB10 通用开漏输出、2 MHz 为 `0x6`。
- 理解配置字段必须先清除再写入；`0100 | 0010 = 0110`，旧位不会被按位或清掉。
- 理解 `IDR` 读取引脚实际采样电平，`ODR` 保存输出控制值；开漏释放时两者可能不同。
- 能判断开漏 PB10 写 1、外部器件拉低时为 `ODR10=1、IDR10=0`；外部上拉且无人拉低时为 `ODR10=1、IDR10=1`。
- 掌握 `BSRR` 低 16 位设置 ODR、高 16 位清除 ODR；`BRR` bit n 写 1 清除 ODR[n]。
- 正确写出同时设置 PA10、清除 PA11 的 BSRR 命令：`(1U << 10) | (1U << (11U + 16U))`。
- 理解 BSRR/BRR 通过单次命令修改目标位，减少 ODR 读改写被中断打断后覆盖其他位的风险。
- 认识 GPIOB 时钟必须先通过 `RCC_APB2ENR` bit 3 开启。
- 了解 `LCKR` 的锁定序列：写 1、写 0、写 1、读 0、读 1；锁定后直到系统复位才能改对应 CRL/CRH 配置。
- 独立写出 PB10 输入上拉的寄存器配置和 `IDR` 读取代码。

## 最终代码

```c
RCC->APB2ENR |= (1U << 3);
GPIOB->BSRR = (1U << 10);
GPIOB->CRH &= ~(0xFU << 8);
GPIOB->CRH |= (0x8U << 8);
int level = (GPIOB->IDR >> 10U) & 1U;
```

按键接地时，PB10 输入上拉的逻辑为：松开读 `1`，按下读 `0`。

## 本次纠正

1. `GPIOB->ODR = (1U << 10)` 会清除其他 ODR 位，不能作为只设置 PB10 的通用写法；改用 `GPIOB->BSRR = (1U << 10)`。
2. `int level = GPIOB->IDR >> 10` 可能保留高位，不能保证结果只有 0 或 1；改为 `(GPIOB->IDR >> 10U) & 1U`。
3. `GPIOB->BSRR = (0U << 26)` 实际写入 0，不会清除 PB10；正确清除命令是 `(1U << 26)`。
4. 开漏输出写 1 是释放引脚，不代表 IDR 必然为 1；实际电平由外部上拉和其他器件决定。
